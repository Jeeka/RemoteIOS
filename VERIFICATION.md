# Проверка iOS-проекта

Состояние на 28 октября 2026 года:

- Исходники находятся в `Jeeka/RemoteIOS`; публичность репозитория изменена с явного разрешения владельца.
- Архив FreeRDP скачан и проверен по SHA256. Подготовка изолированного дерева с применением патчей выполнена локально.
- Проверка SHA256 Android-файлов и готового APK проходит: они не изменились.
- Нативный тест парсера адресов подготовлен для macOS. На Windows он пропущен: Foundation недоступен.
- Два первых запуска Actions остановились до создания заданий. После разрешённого перевода репозитория в публичный третья попытка создала задание, но GitHub не выдал runner и сообщил: `The job was not started because your account is locked due to a billing issue.`
- UIKit/FreeRDP для iOS ещё не скомпилированы. Рабочего IPA пока нет. Установка, поворот, клавиатура, жесты, подключение к RDP/RD Gateway и Keychain на iPhone ещё не проверены.

Последняя диагностированная попытка: https://github.com/Jeeka/RemoteIOS/actions/runs/40675414435

После снятия блокировки аккаунта: Actions → Build MiptRDP for iPhone → Run workflow. Успешный запуск должен выдать артефакт `MiptRDP-iPhone`. Ошибки компиляции, если они возникнут, нужно устранить до установки; наличие исходников не означает успешную сборку.
