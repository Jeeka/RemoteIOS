# MiptRDP для iPhone и iPad

Нативный клиент RDP на UIKit и FreeRDP. Отдельный iOS-проект: Android-приложение и его APK не меняются.

## Возможности

- Список рабочих компьютеров, добавление, редактирование долгим нажатием, удаление смахиванием.
- Имя компьютера, доменная учётная запись, RD Gateway с общими или отдельными учётными данными.
- Адреса DNS, IPv4, IPv6; необязательный порт внутри адреса. Отдельных полей портов нет.
- Пароли в Keychain, без паролей в JSON и исходниках. При выключенном запоминании пароль запрашивается при подключении.
- Небольшой курсор; режим тачпада и прямых касаний; постоянно доступная кнопка системной клавиатуры.
- Вертикальная и горизонтальная ориентация, iPhone и iPad, iOS 16 и новее.

## Сборка без собственного Mac

GitHub Actions использует облачный macOS runner. После отправки исходников в ветку `main` откройте Actions → **Build MiptRDP for iPhone**. Успешная сборка публикует артефакт **MiptRDP-iPhone**, содержащий `MiptRDP-iOS-unsigned.ipa` и SHA256.

IPA не подписан: его нужно подписать локально при установке. В GitHub не нужны Apple ID, пароль, сертификаты Apple или адреса ваших серверов. Первый запуск собирает FreeRDP, OpenSSL и зависимости из исходников и может занять значительное время. До успешного завершения workflow наличие готового IPA не гарантируется.

На Mac вручную:

```sh
python3 -m unittest discover -s tests -v
bash scripts/build.sh OS64
```

Требуются Xcode 26+, CMake 3.30+, Python 3.12+, pkg-config. `bash scripts/build.sh SIMULATORARM64` собирает приложение для симулятора Apple Silicon; такой файл нельзя установить на реальный iPhone.

## Установка с Windows через AltStore Classic

1. Установите **AltServer для Windows** и зависимости iTunes/iCloud по [официальной инструкции](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Нужен AltStore **Classic**.
2. Подключите iPhone кабелем, подтвердите доверие компьютеру и установите AltStore через значок AltServer в системном трее. Вводите Apple ID только в интерфейсе AltServer.
3. Выполните шаги доверия разработчику/Developer Mode, указанные AltStore для вашей версии iOS.
4. Скачайте артефакт Actions, распакуйте ZIP, передайте `.ipa` на iPhone в «Файлы». В AltStore → My Apps → `+` выберите IPA.
5. Для бесплатного Apple ID действует ограниченный срок подписи, обычно 7 дней: обновляйте приложения через AltServer. [Официальные ограничения](https://faq.altstore.io/altstore-classic/your-altstore).

Mac и публикация в App Store для этого маршрута не нужны. Успешная сборка IPA отдельно от проверки установки, подписания и подключения к вашему RD Gateway на реальном iPhone.

## Управление

- Тачпад включён по умолчанию: движение пальцем перемещает курсор, тап щёлкает в его позиции.
- Кнопка руки переключает прямые касания: тап в нужное место рабочего стола, движение удерживает левую кнопку.
- Долгое нажатие в режиме тачпада — правая кнопка; движение после удержания — перетаскивание. Два пальца используются для прокрутки/масштаба средствами FreeRDP.
- Кнопка клавиатуры справа вверху показывает и скрывает системную клавиатуру. Панель специальных клавиш предоставляется нативным клиентом FreeRDP.
- Крестик отключает сеанс после подтверждения. Удалённый Windows продолжает работать.

## Структура и безопасность исходников

`freerdp.lock.json` фиксирует commit и SHA256 архива. `scripts/prepare.py` проверяет архив и создаёт изолированную копию в `.build`, после чего применяет только iOS-изменения. Папки `.build`, `.cache`, `dist`, локальные отчёты и учётные данные не публикуются. Никогда не добавляйте сюда реальные пароли, адреса внутренних серверов, Apple ID или токены.

Невалидный/нечитаемый файл подключений не перезаписывается пустым списком. Keychain использует `WhenUnlockedThisDeviceOnly`. Проверка сертификата остаётся в нативном клиенте: неизвестный сертификат требует решения пользователя. Для корпоративных серверов используйте доверенный сертификат/корневой CA.

## Проверки

`python3 -m unittest discover -s tests -v` проверяет архив и сохранность Android в исходном Windows workspace. На macOS дополнительно компилируется и запускается настоящий Objective-C парсер адресов на Foundation. Workflow компилирует UIKit/FreeRDP для arm64, проверяет платформу, ориентации и зависимости Mach-O перед упаковкой.

Подключение к корпоративному RDP и шлюзу, сетевые ограничения, MFA, экранная клавиатура и поворот требуют проверки на реальном устройстве. Наличие этих возможностей в исходниках не заменяет такую проверку.
